# carpet-YHaddition for Minecraft 1.21.11

Source of the Minecraft 1.21.11 build. See the repository root README for features,
installation and the prebuilt jar (`../../jars/carpet-YHaddition-1.7.1-mc1.21.11.jar`).

Build:

```bash
./gradlew build
```

`libs/` contains the compile-time jars (Fabric API modules, Carpet / malilib) so the
project also builds offline.
