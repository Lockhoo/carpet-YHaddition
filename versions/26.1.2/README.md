# carpet-YHaddition for Minecraft 26.1.2

Source of the Minecraft 26.1.2 build. See the repository root README for features,
installation and the prebuilt jar (`../../jars/carpet-YHaddition-1.5.3-mc26.1.2.jar`).

Build:

```bash
./gradlew build
```

`libs/` contains the compile-time jars (Fabric API modules, Carpet / malilib) so the
project also builds offline.
